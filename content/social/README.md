# Social post drafts

Monthly LinkedIn (10th, 20th) and Instagram (15th, 25th) drafts written by the cloud routines per
`content/CONTENT-PLAYBOOK.md`. One folder per month: `YYYY-MM/linkedin-DD.md`, `YYYY-MM/instagram-DD.md`.

Each file: front matter (date, platform, keyword, blog URL, service, status), the paste-ready post,
then the image prompt(s). Status moves draft -> approved -> posted (with the live link).
